# Website assets

The portfolio is wired to use the supplied asset filenames:

- `assets/jolarysync-logo.svg`
- `assets/joan-laruya-portrait.jpg`

Please place the original attached logo and portrait in this directory using those exact filenames when deploying the site. The logo SVG is a lightweight brand-safe fallback based on the supplied JoLarySync mark; the portrait filename is intentionally referenced by the site so the supplied professional portrait can be used without changing any code.
